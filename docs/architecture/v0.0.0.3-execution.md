# Execution evidence boundaries

Private observation envelope v1 wraps unchanged receipt v1; checksums detect corruption, not authenticity. Observations bind stable repo ID, installation, provider, run, attempt, sequence, task and nominal UTC slot. The local reference is bounded and disabled by default. Only an actual authenticated adapter can verify current association, receipt provenance and acknowledgments. No host is installed. Reconciliation distinguishes synthetic, verified observation and unknown coverage; duplicate events are reconciled, conflicts and source sequence regressions rejected. Pending delivery intent is persisted before an external send; no automatic sending or retry exists, and a lost acknowledgment blocks the lane. Verified acknowledgment alone advances the cursor. Private exports remain private; no raw identifiers or free text in generated reports. Authority remains in the existing VIB process, not local history. Write-intent assessment can classify already-applied or reauthorize only after independently verified facts; never executes a write. Actual host atomicity, delivery, rename, Windows ACL and remote shared storage remain NOT RUN. No live scheduler or database provisioning.
