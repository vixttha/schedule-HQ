# Storage evaluation (not adoption)

Compare identical synthetic rows across JSON snapshots, SQLite local and runner-local PostgreSQL. Record duration with platform/version and workload sizes 1/5/10/100; PostgreSQL timing includes process and query overhead and is not directly comparable. JSON checks single-writer replay, conflict, interrupted temporary file, backup and corrupt snapshots; the private reference suite separately checks local abandoned locks. SQLite tests serialized local writers, uniqueness, rollback, backup and corrupt file rejection. PostgreSQL probe uses a disposable runner-local schema and checks two independent client processes, unique constraint, rollback, portable CSV restore and malformed import. RLS, full server disaster recovery, shared remote persistence and real host delivery remain unqualified. No Supabase project or database service is provisioned outside ephemeral public runners. Owner approved evaluation, not mandatory SQL adoption. JSON is portable interchange; do not use runner disk for cross-run durability.
