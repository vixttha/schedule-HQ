# Storage evaluation (not adoption)

Compare identical synthetic rows across JSON snapshots, SQLite local and runner-local PostgreSQL. Record duration with platform/version and workload sizes 1/5/10/100; PostgreSQL timing includes process and query overhead and is not directly comparable. JSON test is single writer only; SQLite tests serialized local writers. PostgreSQL probe checks uniqueness and rollback only; concurrent server, backup/restore, RLS, remote persistence and real host delivery remain unqualified. No Supabase project or database service is provisioned outside ephemeral public runners. Owner approved evaluation, not mandatory SQL adoption. JSON is portable interchange; do not use runner disk for cross-run durability.
